# Data Description

## Overview

This folder contains the metadata file describing all 123 indicators used in the nowcasting study. The raw macroeconomic panel is **not included** due to institutional data agreements.

---

## Files in this folder

### `meta_data_v2.csv` — Indicator metadata (included)

| Column | Description |
|---|---|
| `series` | Variable code (matches column names in `data_tf.csv`) |
| `name` | Variable description in Spanish |
| `freq` | Frequency: `M` = monthly, `Q` = quarterly |
| `block_g` | DFM block: Global/Real activity (1 = yes, 0 = no) |
| `block_s` | DFM block: External sector |
| `block_r` | DFM block: Financial/monetary conditions |
| `block_l` | DFM block: Labour/fiscal |
| `months_lag` | Publication lag in months (0 = available same month, 1 = 1 month delay, etc.) |

### `data_tf.csv` — Transformed panel (NOT included)

Generated by running `Models/prepare_data_v2.R` on the raw data.
Contains month-on-month growth rates for all 123 indicators, 2005M1–2024M6.

### `SLV_nowcasting_data_mq.csv` — Raw data (NOT included)

Original mixed-frequency panel before transformation.

### `series_selection.csv` — Series selection for the 2026 update (included)

Flags which of the 123 indicators enter the updated dataset (November 2026
update, data through 2026M6). One row per series:

| Column | Description |
|---|---|
| `series` | Variable code (matches `meta_data_v2.csv`) |
| `source` | Publishing institution |
| `last_obs_nov2026` | Last month with data in the November 2026 update |
| `include` | 1 = kept, 0 = excluded |
| `exclusion_reason` | Why the series was excluded |

16 series are excluded, leaving 107:

- **FUSADES business confidence (`CE_*`, 10 series):** no comparable public
  data after 2024M6.
- **ISSS contributors (`ISSS_*`, 3 series):** no comparable public data after
  2023M12.
- **`INGC_TRP`, `TPR1`:** not updated after 2024M6.
- **`IMP_D_BCB`:** near-zero values with four months at exactly 0.0, so the
  growth rate is undefined.

Imputing two or more years of missing data with seasonal averages (as the
Excel tab `MAIN-RAW-1` would do) would feed fabricated values to the models,
so these series are dropped rather than filled.

`apply_series_selection.py` builds the reduced dataset from a `data_tf.csv`:

```bash
python Data/apply_series_selection.py <input_Data_dir> <output_Data_dir>
```

The robustness check comparing both sets on the original evaluation sample is
`Evaluation/03_series_selection_robustness.py`.

### Running from another folder

All scripts read their paths from the environment variable `ESA_BASE_DIR`
(default `~/Desktop/ESA-gdp-nowcasting`), so the same code runs on the desktop
or in a cloud workspace:

```bash
export ESA_BASE_DIR=/path/to/project   # must contain Data/ and Models/
Rscript Data/prepare_data_v2.R
```

`Models/DMF.R` also reads `ESA_DFM_ROLLING` (`TRUE` by default) to switch
between re-estimating the DFM at every origin and estimating it once.

## Variable Naming Convention

Variables follow the naming convention used by the BCR:

- `IVAE_TOT` — IVAE total (economic activity index)
- `IVAE_AG` — IVAE agriculture sector
- `GDP` — Quarterly GDP growth rate (QoQ)
- `GDP_AG` — GDP agriculture sub-sector
- `CE_TOT_VV` — Total commerce, nominal
- `EXP_CO` — Exports, coffee
- `REM` — Remittances
- `TIP_30` — 30-day lending rate
- `INGT_IVA` — VAT tax revenues
- `UNEM_US` — US unemployment rate
- `EFFR_US` — US effective federal funds rate

## Transformation Details

All series are transformed to month-on-month growth rates using:

```
growth_rate(t) = (x(t) / x(t-1)) - 1
```

Exceptions:
- Interest rates: first differences (percentage point changes)
- Survey indices: levels
- Series already in rate/index form: levels or first differences as appropriate

See `Models/prepare_data_v2.R` for the complete transformation pipeline.

## November 2026 update: running the full pipeline

1. **Recalculate the Excel formulas** (open and save in Excel, or
   `soffice --headless --convert-to xlsx`). If the workbook was edited by a
   script, the formula tabs (`MAIN-RAW-1`, `MAIN-DEFLATED`) keep stale cached
   values until recalculated.
2. Export `MAIN-DEFLATED` to `Data/SLV_nowcasting_data_mq.csv` (columns
   `date` + the 123 series in `meta_data_v2.csv`) and run
   `Rscript Data/prepare_data_v2.R`.
3. Build the 107-series dataset:
   `python Data/apply_series_selection.py <full_Data_dir> <reduced_Data_dir>`.
4. ML models and benchmarks (evaluation 2020Q1–2026Q1 plus the 2026Q2 nowcast):
   ```bash
   python Models/ml_nowcast_v2.py --base $ESA_BASE_DIR --out <dir> \
       --cv tscv --impute regression --models ridge,lasso,rf,xgb,bench \
       --test-end 2026-03-01 --nowcast-date 2026-06-01
   ```
5. MIDAS and DFM:
   ```bash
   export ESA_TEST_END=2026-06-01
   Rscript Models/MIDAS.R
   ESA_DFM_REESTIMATE=annual Rscript Models/DMF.R   # or: every | once
   ```
6. `python Evaluation/04_updated_evaluation.py <dir> $ESA_BASE_DIR <out_dir>`
